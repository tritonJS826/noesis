# Лендинги

Статические страницы проекта **noesis**. Это не отдельный интерфейс приложения: папка
не подключена к Go-коду и не участвует в сборке бинарников.

- `index.html` — основной лендинг: локальный второй мозг, приватность на своём железе,
  запуск всего пайплайна одной кнопкой, примеры с дневником и оценкой новизны.

## Посмотреть локально

Откройте `index.html` в браузере или раздайте папку статическим сервером:

```sh
python3 -m http.server 8000 -d landings
```

Затем откройте <http://localhost:8000>.

Страница самодостаточна: CSS встроен, внешние шрифты и картинки не используются,
поэтому она работает офлайн. Новые лендинги можно добавлять рядом отдельными
HTML-файлами.
